# Invory · Регистри на активи

React, Vite и Tailwind CSS. Началният екран показва организационните регистри. При създаване Invory отваря новия регистър, от който се добавят и преглеждат активите.

## Стартиране

```sh
npm ci
npm run dev
```

За production build използвайте `npm run build`. Резултатът е в `dist/`.

## Файлове

- `src/App.jsx` управлява навигацията и състоянието на приложението.
- `src/components/RegistryViews.jsx` съдържа началната страница, списъка с регистри и таблицата с активи.
- `src/components/RegistryDialogs.jsx` съдържа формите и прегледа на актив.
- `src/registryStore.js` валидира записите и ги пази локално в браузъра.
- `src/index.css` задава темата и общите Tailwind стилове.

Регистърът изисква име. За актив са задължителни наименование, инвентарен номер, местоположение и положително количество. Инвентарният номер е уникален в рамките на регистъра.

Данните в тази версия се пазят в `localStorage` на текущия браузър. Слоят в `registryStore.js` е мястото за свързване с бъдещия ASP.NET Core API.
